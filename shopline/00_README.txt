ruff. 藍夫｜9/1 文章 上稿到 SHOPLINE
====================================

【重要】HTML 模式下不能直接按儲存
SHOPLINE 會擋下來並提示「請先切換到一般內容編輯模式」。
正確順序：貼上 → 再按一次 <> 切回一般模式 → 確認排版 → 才按儲存。


方案 A（先試這個，最省事）
--------------------------
檔案：01_shopline_paste.txt
1. 部落格 > 新增文章 > 內文編輯器按 <> 進入 HTML 模式
2. 全部貼上（含最前面的 <style>）
3. 再按 <> 切回一般模式
4. 看排版有沒有跑掉
   - 正常 → 直接儲存，完成
   - 變成沒有樣式的純文字 → <style> 被過濾掉了，改用方案 B


方案 B（<style> 被吃掉時用）
----------------------------
把 CSS 放到主題的自訂樣式，文章內只放 HTML。
這樣做反而更好：CSS 只寫一次，之後每篇文章都能共用。

步驟 1：貼 CSS
  檔案：02_css_only.txt
  後台 > 商店設定 > 自訂程式碼（或 網店設計 > 進階設定 > 自訂 CSS）
  貼進 <head> 或自訂 CSS 欄位。
  ※ 所有規則都限定在 .ruff-post 底下，不會影響網站其他地方。

步驟 2：貼文章
  檔案：03_body_only.txt
  文章內文編輯器 > <> HTML 模式 > 貼上 > 切回一般模式 > 儲存


如果連方案 B 也不行（找不到自訂 CSS 欄位）
------------------------------------------
代表這個方案要改成「圖文版」：
VS Banner 因為用 CSS 偽元素做斜切，無法用行內樣式重現，
必須輸出成 PNG 圖片插入。請回報，會另外處理。
