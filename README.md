### 03 為什麼取代 02

同一個檔期、同一個對手，換切角。02 是「保健品成分開箱」，主體是對手的品類，
讀起來像同業互打，也把我們放在防守位置。03 把主體換成**毛爸媽真的用得到的
放鬆方法**（10 種做法 ＋ 一週舒壓菜單），只在倒數第二節放一段誠實提問與
〈挑選情緒商品的三個問題〉。**火力放在方法論，不放在品牌**——破口讓毛爸媽
自己對照發現，我們一句都不用點名。

02 的成分證據表（α-casozepine／L-茶胺酸／GABA／色胺酸／草本／益生菌）與
「正常 vs 值得留意」雙欄對照仍有價值，可留給日後獨立成篇，所以檔案不刪。

### 品牌語氣校正（2026/09/15，POST 03 與 POST 04）

第一版的 03 與 04 口吻偏冷、偏評論文體，與 ruff. 實際發文的語氣不符。已參考
官網已發佈的〈為什麼狗狗這麼愛咬東西？破解毛孩的「搞破壞」心理學〉（8/2）、
〈感謝訂閱者一路支持！再次認識【ruff. 藍夫】〉（7/23），以及 9/1、9/3、9/8、
9/16 的實際 IG 貼文，整篇重寫。**四條規則，後續修稿請沿用：**

1. **主人的稱謂以「毛爸媽」為主**（原稿通篇「家長」，與官網實際用法不符），
   「訂閱者」「你們」為輔。
2. **小標改成完整句子，不用冷冰冰的短標**；品牌名在強調處寫成 **【ruff. 藍夫】**，
   產品寫成「寵壞盒」（加引號）。
3. **拿掉冷調的評論式句法**。已重寫的例子：「老實說」「先講一件我們不打算含糊
   帶過的事」「這段話對業績可能不是最有利的寫法」「這一彈不是。」
4. **句子拉長、語氣上揚**，補上驚嘆號、「喔」「～」、段落 emoji，以及 ruff.
   慣用的四字語（崩潰瞬間、引頸期盼、功成身退、源源不絕、從不妥協等）。

**狗的代名詞維持「他」。** 官網已發佈的文章用「牠」，但經確認品牌可接受
「他」，本系列統一用「他」，請勿再改。

04 的門市提醒直接沿用 9/16 貼文的原句式：「溫馨提醒：門市現場僅供實體展示，
沒有直接販售喔！」

## 審稿注意事項

- 所有頁面均設 `noindex, nofollow`，並附 `robots.txt` 全站禁爬，不會被搜尋引擎收錄。
- 文章中**紅色虛線框的 `【待填】`** 需由營運／法務／vacanza 提供實際數字，上線前補齊或整段移除；**橘色虛線框的 `【待確認】`** 是會改動內文寫法的決策點。
- **每篇的「編輯備註」都寫了該篇的語氣規則**，修稿前先展開看一次。
- 每篇最上方的「編輯備註」`<details>` 區塊，正式上線至官網 CMS 時請刪除。
- 全文不點名任何同業品牌，不放競品截圖，不對他牌產品效果做斷言——此立場請於審稿時一併確認。
- **第一篇已改為主題／產品文**，聚焦九月聯名內容與客製化玩具，不做選購教育文。
- **第三篇（9/15）的火力全在〈挑選情緒商品的三個問題〉**：成分與菌株菌數是否揭露／引用的研究是否做在狗狗身上／毛爸媽要怎麼驗收效果。這三問對我們自己的商品也必須成立，否則整篇雙標——所以自家保健品的兩處【待填】拿不出來就整段刪除，不要留白。
- **第三篇有 3 處研究引用**（橘色虛線「引用待核」）需研發／法務逐條核對，核不到的整句刪掉，段落不會塌。清單見 `shopline/07_seo_fields.txt`。
- **第四篇（9/16）最重要的一條紅線：這一彈的設計不是我們做的。** 絕不可沿用「獨家開發訂製」「外面買不到」。第一彈的主視覺可以寫「只在 RUFF. 才有」，因為那顆玩具真的是我們開的版、拿得出產線影片；第二彈是 Haydonna × vacanza 的設計。
- **第四篇的「門市僅展示、不販售」要寫得夠大。** 9/16 與 9/18 兩篇貼文都特別強調，本文放在第 4 節的橘色提醒框，請勿為了版面精簡把它縮小或移到附註——會有毛爸媽專程跑一趟。
- **第四篇門市名稱兩篇貼文寫法不一致**（`中山 vacanza Lab` vs `Lab.`、`中山 Ruby's 複合店 (Crush!)` vs `中山 vacanza crush!`、`西門假期貿易公司` vs `西門 假期飾品貿易公司`），本文暫採 9/18 版，上線前必須向 vacanza 統一。
- **客製化說法須保留餘地**：九月首次做到全客製化，之後盡量延續但不作絕對承諾。切勿改寫成「一直都是全客製化」。
- 商務條款（採購價、抽成 %、訂閱主／會員人數、寄賣條件、月結方式）為內部資訊，**不得寫入對外文章**。
